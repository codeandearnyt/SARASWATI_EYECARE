## Premium interaction reference

The 21st.dev catalogue includes dimensional interaction and background patterns. The selected direction for this project is not entertainment-style 3D; it is a calm, depth-led “clinical refraction” treatment using layered translucent planes, gently tilting information cards, image parallax, and a luminous eye-care focus field. It will preserve readability, keyboard access, and reduced-motion support.

## Integration decision record

The static project requires a public form endpoint or client-side provider key to deliver appointment emails. No Formspree connector is configured in the current session. A real EmailJS or Formspree connection cannot be activated without a user-provided endpoint or credentials. The enhanced user interface will therefore support a provider-ready submission adapter, live validation, loading feedback, failure feedback, and a local management preview until the clinic supplies the required provider setup.
