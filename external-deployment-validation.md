# External Deployment Validation

The external Vercel repair is configuration-based: `vercel.json` routes every existing `/manus-storage/*` asset path to the published project storage endpoint before the single-page-app fallback. This covers the logo, clinic photography, clinician portraits, Google Maps mark, video thumbnails, favicon, and preload assets without duplicating media into the deployment bundle.

The local server serves `/.well-known/security.txt`, and the production output includes that file without source maps. The public homepage also remains visually intact after the deployment configuration change. The sandbox could not make a direct TLS connection to the published Manus domain during an asset probe, so final external confirmation requires redeploying the included `vercel.json` on Vercel and checking the live browser network panel.

The shared footer was rechecked at 375px and 768px viewports after its grid and embedded-map containment repair. At mobile it becomes a single `minmax(0, 1fr)` column; at tablet it uses two containment-safe columns. The Google map remains within its card width with a bounded aspect ratio and no visible right-edge overflow.

The current verified source was pushed to `https://github.com/codeandearnyt/SARASWATI_EYECARE` at commit `9b7bfa1` (`Fix responsive footer and Vercel asset delivery`). Vercel accepted a production deployment for `https://saraswati-eyecare-hyo15xj0m-codeandearnyt-9184s-projects.vercel.app`, with the production alias `https://saraswati-eyecare-codeandearnyt-9184s-projects.vercel.app`. The Vercel inspection output confirms the managed-storage rewrite and configured CSP, MIME, referrer, and permissions headers. Browser access to the alias is currently intercepted by the Vercel SSO/protection login page, so direct public asset and header validation remains blocked until that protection is disabled or a bypass is supplied.

The project was then deployed from a clean, non-Git Vercel workspace because the first direct source deployment was blocked by Vercel's commit-author collaboration policy. The current public production alias is `https://saraswati-eyecare.vercel.app`. Browser validation confirmed the homepage, logo, and hero area render publicly. Direct HTTP checks confirmed the managed-storage rewrite resolves the logo, favicon, preload image, and video thumbnail paths (all return an expected signed-storage redirect), while the live `security.txt`, Content-Security-Policy, `X-Content-Type-Options`, Referrer-Policy, and Permissions-Policy headers are present.
