# Original Hero Typography Reference

The original clinic hero renders its headline in `Segoe UI, Arial, Helvetica, sans-serif` at `font-weight: 800`. The `Google Reviewed` line uses a left-to-right purple gradient from `#7157A0` through `#8B6BC4` back to `#7157A0`, clipped to the text, with a soft `2px 2px 4px rgba(255,255,255,.5)` shadow. This reference supports applying the same emphasis treatment to the eye-hospital phrase in the redesigned hero.
